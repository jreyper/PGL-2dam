# Extensiones que usaremos

Esto son las extensiones clave que utilizaremos en el curso para el desarrollo con JavaScript, TypeScript, React, Expo y React Native.

| Tecnología | Extensión | Creador / Origen | Función Principal |
| :--- | :--- | :--- | :--- |
| **JavaScript** | JavaScript (ES6) code snippets | dsznajder | Atajos y fragmentos de código moderno. |
| **TypeScript** | TypeScript Nightly | Microsoft | Herramientas avanzadas y tipado en tiempo real. |
| **React** | ES7+ React/Redux/React-Native snippets | dsznajder | Generación instantánea de componentes y hooks. |
| **Expo** | Expo Tools | Expo | Validación de `app.json` y depuración móvil. |
| **React Native** | React Native Tools | Microsoft | Depuración integrada y comandos de consola. |

## Descripciones de las Extensiones

### 1. JavaScript (ES6) code snippets
* **Categoría:** Productividad / Snippets
* **Descripción:** Con esta extensión podemos escribir más rápido JavaScript. Permite generar estructuras comunes (como funciones flecha, bucles e importaciones) utilizando abreviaciones.
* **Ventaja:** Evita tener que escribir código repetitivo manualmente en cada archivo.

### 2. TypeScript Nightly
* **Categoría:** Linter / Lenguaje
* **Descripción:** Desarrollada por Microsoft. Incluye las últimas mejoras en detección de errores, refactorización y autocompletado inteligente.
* **Ventaja:** El editor puede detectar cualquier fallo de tipado al momento con el rendimiento más rápido posible.

### 3. ES7+ React/Redux/React-Native snippets
* **Categoría:** Productividad / React
* **Descripción:** La extensión estándar de React. Permite crear componentes funcionales enteros, configuraciones de Redux o código para React Native en un segundo mediante comandos cortos (como `rafce`).
* **Ventaja:** Reduce mucho el tiempo de configuración inicial de cualquier archivo de componente a cero.

### 4. Expo Tools
* **Categoría:** Herramientas de Desarrollo / Mobile
* **Descripción:** Es la extension oficial, se encarga de validar el archivo de configuración `app.json`, autocompletar sus propiedades y facilitar la depuración de aplicaciones móviles directamente desde el editor.
* **Ventaja:** Es muy impotante si quieres mantener la configuración del proyecto móvil limpio sin errores.

### 5. React Native Tools
* **Categoría:** Depuración / Mobile
* **Descripción:** Es la extensión oficial de Microsoft orientada al móvil. Añade un entorno de depuración integrado que se conecta directamente a los simuladores de iOS o Android.
* **Ventaja:** Nos ayuda a buscar y solucionar fallos lógicos mediante breakpoints directamente en el código de la app en ejecución.
